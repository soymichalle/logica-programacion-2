# Conversor de Temperatura

Proyecto desarrollado en JavaScript para convertir temperaturas de grados Celsius a Fahrenheit y Kelvin.

# Lanzado en:

https://conversor-de-temperaturas-mich.netlify.app

## Funcionalidades

- Ingresar una temperatura en grados Celsius.
- Convertir la temperatura a grados Fahrenheit y Kelvin.
- Validar los datos ingresados.
- Mostrar los resultados en la interfaz.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Fórmulas

- Fahrenheit: (°C × 9/5) + 32
- Kelvin: °C + 273.15

Desarrollado como práctica de lógica de programación.
